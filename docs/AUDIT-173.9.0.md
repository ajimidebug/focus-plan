# 173.9.0 实施与验证

## 修改

1. 同时约束 html、body、主内容和页面结构的宽度，针对 Android 将 html 横向溢出保护由 clip 改为 hidden，body 使用 clip 保留头部粘性定位。保留组件局部滚动、纵向页面滚动和浏览器缩放，不拦截触摸事件。三栏标题、积分和表单在栏内收缩、换行。
2. 五栏导航保持固定。可见视口变化时计算底部避让位置，预留实际导航高度与安全区。普通滚动不切换显示；缩放期间不反向干预浏览器平移。ResizeObserver、resize、pageshow 负责重新定位，不轮询、不改换页面滚动容器。
3. 确认完成与打卡共用弹窗删除计时摘要和进度条，同时删除对应刷新路径。保留计时按钮、执行时段折叠项、备注、预计用时、完成说明、积分和保存重试逻辑；弹窗最大宽度400px，计时按钮至少44px高。
4. 悬浮用时刻度统一使用已有有效时段并集；普通任务累计、每日项目与习惯按当前04:00用户日统计。先前会话用浅色，当前未结束会话用亮色；重叠时间优先归入此前部分，确保两部分之和等于去重累计。暂停继续不换会话，结束重开与刷新恢复依赖持久化会话身份。
5. 预计时长保留为累计轴上的固定界线，超过后自动进入超时状态。范围不足时按倍增档扩展；不再按小时取余或把累计刻度清零。超时底纹和界线与会话颜色分别表达。没有预计时长也使用累计刻度，不显示完成百分比。
6. 三栏在现有只读统计上新增未完成延期数和浅色段，涵盖原日期保留项、自动顺延和手动跨日安排。已完成优先；关闭的历史安排不重新进入分母；后续完成不自动改写原日期完成率。奖励和历史账本不变。
