# 173.4.1 有效积分收支审计

基线：main `299156e2cc1cbe511876e377890ccbf0db7cefdb`（173.4.0）。回退分支：`release-173.4.0-rollback-20261029`。

## 行为

总积分、今日收支和积分页兑换入口打开同一个“积分明细与兑换”窗口。默认展示今日全部类型流水，可切换全部历史；自定义支出、固定兑换和消费撤销保留。

顶部及弹窗摘要显示有效收支。同日原操作与有可靠关联的撤销合并；例如合成数据中的+25和−25同时排除后，收入29／支出145变为有效收入4／有效支出120，净变动仍为−116。原始正负流水保留并标注全额抵消、部分抵消或恢复合并。

跨04:00的撤销在新用户日单列跨日调整，不计为当天新收入或新支出；此前日期的入账统计不随后续正常撤销重算。手工调整和不能可靠关联的纠正单列其他调整。恒等式：有效收入−有效支出＋跨日调整＋其他调整＝当日全部原始流水之和。

## 关联与数据保护

- 以可靠的 `at` 入账时间及北京时间04:00归日；行为日和经济生效时间另列。无可靠入账时间的旧记录保留余额及全部历史，不猜测归日。
- 通过唯一流水编号和 `refundOf` 归组；旧习惯漏打卡通过结算记录中的确切流水编号顺序关联，旧逾期纠正通过确切结算编号关联。金额、名称、时间接近均不作为猜测配对依据。
- 对完整关联链按入账用户日计算，包括撤销后重做、负分撤销、部分抵消、删除／恢复／再删除。新习惯纠正和逾期豁免使用已有 `refundOf` 字段补齐关联，不变更数据版本。
- 缺失来源、重复编号、相同方向的纠正、超出原额、关联循环和不可靠时间均不静默隐藏。可归日金额保留在其他调整并提示关联待核验；原始余额始终不受投影影响。
- 有效统计为只读计算；余额、银行利息、复制事实基线和账本保存流程不改写。复制／导出保留逐笔原始数据，并标注原始流水统计含撤销。
- 全部用户文字和流水编号转义。关联建立使用索引，处理后不持久化派生状态；导入、刷新和旧版回退不依赖新增统计快照。
- 此版本不包含任务权重排序，不修改任务结构、计时、奖励、罚分数额或银行利率。
