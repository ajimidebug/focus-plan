# 173.6.0 时间轴分轨、悬浮窗位置与积分表单审计

基线：173.5.0，`fdc172c50a755445a3450352e3bbd62d02812ef6`。保留该版本的延期快照、默认积分迁移和自动超时刻度。本次不迁移数据结构，不重新结算历史积分或计时。

## 时间轴

- 默认综合视图使用同一时间刻度，按“预计／计时／完成”分为三轨；固定42px刻度区，其余宽度按3／4.4／2.6分配。浅色背景、边框、来源文字和轨道标题共同区分记录。对照视图调换计时与预计位置；仅计划、计时与完成视图继续可用。
- 只有明确保存的具体安排才出现在预计轨道；仅设置预计分钟数不推测起止时间。未安排的直接执行仍显示在计时轨道，未安排列表保持原含义。
- 计时继续使用现有会话的原始片段，暂停间隔不作为执行时间。手动补记、原版自动记录和小时代汇总保留来源；汇总使用虚线，不变更统计口径。
- 完成与打卡只显示发生时刻，固定大小的点击标记不代表持续时间。任务有无计时通过保存的执行明细判断；不以标题相同猜测关联。
- 密集记录在各自轨道内聚合，以虚线框、“几条记录／几次完成”和展开提示区分；展开后每条原始记录可跳到对应详情。聚合外框不作为连续执行时段或额外时间累计。
- 运行中的单条及聚合条继续逐秒更新高度，不重建整个图表。当前时间线置于记录下层，避免覆盖标题。短记录标题清除旧版绝对定位、双边框和连线样式，完整内容在详情中查看。
- 显示窗口按左闭右开截取，避免刚好位于窗口末端的时间点在相邻窗口重复。北京时间04:00用户日切分仍复用原规则；跨日计划与会话按所选日期截取展示，不拆成新会话。

## 悬浮窗

正常高度的视口将顶部放在可见高度24%左右，限制在144—260px；横屏和短视口使用较高位置并限制剩余空间。使用`visualViewport.height`和`offsetTop`响应键盘缩小视口及可见区域偏移，缺失时退回窗口高度。展开与缩略使用同一顶部锚点，底部留出导航空间，内容过高时内部滚动。

保留输入随手记时缩略、模态窗口打开时隐藏、进度条及自动超时的原有逻辑，不增加独立计时状态和位置持久化。

## 任务表单

- 三栏共用任务编辑器实际DOM顺序改为：栏目、名称、完成积分、备注、其余设置；日期提示和底部操作继续固定。
- 完成积分使用独立容器，必做栏目整组隐藏；不再通过相邻元素位置寻找积分标签。预设加分按钮随容器一起隐藏。
- 长期拓展的分组字段放到备注后面，避免把积分再次挤出首屏。编辑既有任务保留原积分；未手动输入时跟随栏目默认值，手动输入的0或自定义值切换栏目后保留。
- 沿用现有保存事务、失败后只重试持久化和保存并开始机制；测试检查重试不会重复创建任务。Node中的两个模态窗口替身补齐新增样式类所需的`classList`接口，不改变原有断言。
