# 173.8.0 实施与验证

基线：main、gh-pages均为173.7.0，提交 `c46e9dc5223f5a43ec0042d47d3d78003ff9b497`。不读取用户手机数据；所有功能验证使用隔离合成数据。

## 行为与审计

- 本次备注是完成事件的独立字段，不覆盖任务长期备注。默认笔记预览包含备注；用户编辑最终文段仍保留其内容；清空文段也保存结构化备注，完整复制补充。嵌套调整安排返回保留备注、预计用时及文段；计时刷新不抢焦点。
- 延期沿用同一任务ID和原日期快照。补记默认采用打开的原日期；记录的录入时间与报告完成用户日分开。每次退款具有独立流水ID；撤销按该次ID抵消，避免多次循环后少扣。撤销补记恢复之前的安排，只恢复未被后续修改的关联计划，不删除执行时段。
- 时间轴计时轨按真实区间分列，标签空间不再把不重叠片段合成长色块。短片段仍可能不能直接显示完整文字，可点击查看精确起止点；来源、任务身份和片段编号保留。完成时刻仍是点，不推测实际用时。
- 固定周期单独保存模板及稳定期次引用，执行复用普通任务。无新增积分通道，无后台定时能力。按北京时间04:00用户日取日期；当前仅设置用户日，无小时级固定周期。隔N天锚点不随完成漂移；每月31日缺日取月底后下月仍回31日。
- 周期创建前不追溯。未打开应用的漏期保留原日期，不自动进入当日积压或扣分；查看未来日期时按需准备期次。跳过不发分；必做跳过仍作为未完成义务。修改后续规则不改写已完成及已开始期次，单期内容修改使用普通编辑。
- 复习模板按逐轮实际确认完成时刻起算，不声称最优记忆模型；已有独立下一轮默认保留。补记只有完成日期时不推算准确实际间隔。旧系列默认手动安排，旧记录不自动接入模板。
- 保存继续使用现有事务：业务错误回滚；持久化失败只重试保存、不重复业务动作。新增周期模块及关联校验、模板边界校验；新字段进入备份及删除差异恢复。
