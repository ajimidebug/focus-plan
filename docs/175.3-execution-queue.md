# 175.3.0 · 每日执行队列与截止日期优化

## 变化

- 在三栏后、甘特图前放置执行队列。队列只保存规范化任务引用与顺序（`memoExecutionQueue`），不创建任务副本、不转移三栏任务。
- 三栏任务快捷入队、多选加入、去重、置顶、上下移动、移至队尾、直接跳过及原任务安全删除入口。
- 跳过仅移除队列引用，无惩罚、历史事件和积分流水；已完成任务在原业务事务中成功保存后退出队列，撤销完成不会自动重新入队。
- 队列内可以使用现有计时入口，但当前项退出后不会自动开始下一项计时。跨日不自动改期。
- 调整安排时直接显示最近七天、可选择其他日期和三栏，不隐藏在「更多设置」下。
- 截止日期置顶后常驻，额外显示最近两个普通未过期日期；甘特图全局截止线标首字，点击查看完整内容；左侧任务名限制为两行、最多五字加省略号。
- 不修改时间轴手势、历史汇总修订、原队列任务池或顶层 `dataVersion=1`。

## 安全与验证

旧备份没有 `memoExecutionQueue` 字段时视为空队列。入队不影响原任务安排或历史；任务结束和数据删除不留悬空引用；删除仍使用现有确认和恢复记录。验证 360/390/430 手机宽度、无整页横向溢出、计时及完成事务保存失败路径、任务改期和跨日引用，以及全局截止日期置顶、过期与标记碰撞。
