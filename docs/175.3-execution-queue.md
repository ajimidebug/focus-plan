# 175.3.0｜每日执行队列与全局截止日期优化

## 已实施的规则

- 三栏下方、甘特图上方增加「执行队列」。队列仅保存任务规范引用与排序，不复制三栏任务。
- 点击三栏任务下方「＋队列」可快速加入；队列面板也可以批量选取三栏未完成任务与当日习惯。
- 顺序支持置顶、上移、下移、移至队尾；点击跳过立即移出队列，不写入跳过历史、不改原任务和积分。
- 删除原任务经既有确认与恢复流程；结束计时仍由现有计时控制。完成时在同一事务移除队列引用，保留不封顶习惯的继续打卡特性。
- 调整安排时直接展示最近七天、栏目选择及其他操作，完整日期选择器作为补充。
- 全局截止日期增加置顶；三栏上方显示全部置顶节点与最近两个普通未过期节点；已过期置顶节点继续展示。
- 甘特图的全局 Deadline 使用垂直虚线和单字标记；点击标记查看完整名称；任务条右端仍表示独立任务计划日期。
- 甘特图左侧任务名缩为两行，最多五字加省略号；原始任务名称保持完整。

## 数据安全与排除范围

- 使用可选字段 `memoExecutionQueue: Array<{ref,pinned}>`，旧数据可以不含本字段，顶层 `dataVersion` 仍为 1。
- 日常计时、积分、笔记、任务历史均由原模块结算。跳过不产生事件，但完整备份仍能回溯到跳过之前的历史版本。
- 未修改原时间轴空白点击/拖选、历史汇总修订、老版队列任务副本逻辑。
- 校验涉及：引用跨日、任务移动/删除、重复加入、排序、完成后一次性清理、旧备份兼容、移动端横向溢出。
