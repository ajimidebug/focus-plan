# 174.1.0 视觉与移动端兼容修复

本版本只调整 174.0.0 的 Vue/Quasar 界面层，基线是 173.9.1 任务概览、深色导航与紧凑弹窗。保留所有现有领域模块与 `focusPlanData.v1`，不改变积分、复习、计时和备份数据。

## 修复范围

- 顶部和五项底部导航恢复旧版深色调与活动项提示，同时保留 174 的路由与状态反馈。
- 原先被隐藏的“扩展”和“辅助”统计项重新可见；手机顶栏采用独立横向滚动的单行指标条，避免增加固定头部高度；整页仍禁止横向拖动。
- 三栏仍同时可见，标题采用旧版纵向排布和栏目浅色强调；减少容器额外边框，任务保留左侧类别色条。
- 手机上任务名称保持至少 13.5px，次要信息不再普遍缩成 9–10px，长名称允许完整换行。
- 三栏顶部保留四段进度条和读屏计数，去除重复显示的“延期 X 项”文字。
- Quasar 弹窗恢复较紧凑的视觉密度，沿用已有两行操作布局、日期确认、保存失败保护。
- 移除外壳对全部遗留卡片和按钮的通用重绘，减少深色等主题的回归。

## 验收和发布边界

正式构建验证：`npm ci`、`npm run check`、`npm run build`、`npm run typecheck`、`npm test`，以及现有 12 组 Playwright 浏览器矩阵。浏览器脚本新增统计项显示、固定五项导航、三栏标题布局、任务字号与无横向溢出断言；原有任务创建/完成/撤销、保存、离线恢复和 173.9.1 兼容界面回归仍保留。

CI 通过后只生成已验证 SPA 发布候选分支 `release/174.1.0-built`；必须另外审核并合并到 `gh-pages`，才能视为线上发布。发布前保存原 `gh-pages` SHA 供回退。真实 Android Edge 的触摸、输入法、键盘遮挡和后台恢复仍需用户设备验收，不能因 Playwright 通过而宣称完成实体手机验证。

保留旧数据结构；版本代码回退不等同于本地用户数据回退。更新前应在用户浏览器导出独立完整备份。
