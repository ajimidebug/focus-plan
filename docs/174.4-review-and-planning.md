# Focus-plan 174.4.0 · 复习管理、信息可读性与长期任务计划

基线：已通过 CI 并发布的 174.3.0；保留 174.1 的三栏布局、174.2 的状态与计时修复、174.3 的权重和悬赏逻辑。此版本继续使用主数据 `focusPlanData.v1`。

## 功能

1. **复习导出**：在“复习任务”折叠区域提供 JSON 和 CSV。JSON 含系列、轮次、稳定 ID、关联任务快照、计划时间点和关联完成事件；CSV 包含每轮当前与原定时间、状态、结果、备注和调整次数。独立文件用于审计，**不能当作主数据完整备份导入**；如需可恢复备份，使用“设置 → 下载完整备份（含图片）”。
2. **轮次备注**：完成时可填写“本次复习备注”“下次复习目标”，分别写入轮次与事件快照；自动生成下一轮时，将下一轮目标放入准备备注。待复习轮次可在历史管理中编辑自己的准备重点；对旧记录不强制补字段。
3. **轮次可见性**：管理界面呈现当前计划、原定计划、完成时刻、实际间隔及本轮/下轮备注。尚未生成的下一轮不伪装成已确定日程。
4. **时间轴与愿望单**：工具按钮重新按响应式网格排版；愿望单对每个目标显示“当前余额占所需比例”，强调所有愿望使用同一积分余额，进度不能累加。积分账本、兑换规则不变。
5. **长期任务甘特图**：使用既有 `memoProjects`；项目编辑提供可选开始/截止日期、项目依赖选择与循环依赖校验。只读计划时间条显示日期跨度和日历时间经过比例；已完成日打卡数量单列。主体页面不横向滚动，甘特图自身可横向滚动。没有日期的旧项目仍正常显示为“未设定计划起止日期”。
6. **兼容**：项目可选字段 `memoGanttStart`、`memoGanttEnd`、`memoGanttDependencies`；复习轮次可选字段 `memoThis`、`memoNext`、`prepNote`。所有历史积分、计时、任务 ID 与复制时间戳保持原义。没有执行迁移或重算。

## 发布验收

必须通过现有 Node/存储、完整 Quasar 构建与 typecheck、13 组现有浏览器矩阵和新 `interaction-1744.browser.cjs`。新测试使用隔离合成数据检查导出字段、依赖环拦截、甘特计划编辑保存、愿望单提示及 320/390/1280 宽度下无页面横向溢出。真实 Android Edge 的触摸、键盘和屏幕缩放需在实际设备另验。

先保留 174.3 源码和 `gh-pages` 原 SHA 回退分支。合并 `main` 后，CI 只构建并推送 `release/174.4.0-built` 发布候选；核对 `version.json` 的 `sourceCommit`、资源校验和构建绿灯，再将候选发布到 `gh-pages`。上线不等于清除缓存，应用自身更新提示仍遵守原备份及活动计时保护。
