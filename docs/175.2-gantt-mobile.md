# 175.2.0 · 移动端甘特图重设计

## 改动

- 任务名称固定在左侧，右侧统一日期轴支持独立横向滚动，日期参考线只绘制在日期轴内。
- 默认自然月视图，简化为分组、创建、视图设置与月份导航两行控件；保留半年、两年、全部时间范围。
- 任务行仅显示名称、类型、依赖异常及计划区间，取消“已过去时间比例”填充，避免误认为实际任务完成率。
- 未排期、其他日期和已达成项分区折叠；未分组默认收起；所有原任务引用与完成历史仍存在。
- 日期选择器和前置依赖列表默认折叠；依旧支持日期范围、单日、仅截止日、清空、同组及跨组依赖。
- 日期选择器使用中文语言包和本地 SVG 路径，不依赖外部图标字体。
- 修复模块导入时，仅截止日的长期项目丢失截止日期的问题。

## 数据与验证

不修改顶层 dataVersion，不建立甘特专用任务副本，不更改三栏安排日、04:00 用户日、历史计时与积分。
发布前应检查不同手机宽度、分组折叠、依赖、导入导出、旧数据及 GitHub Actions 构建与浏览器验证。
