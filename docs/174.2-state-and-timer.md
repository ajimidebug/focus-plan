# 174.2.0 · 复习状态、计时和完成事件一致性

上一版 174.1.0 的 Vue 3 / Quasar 视觉恢复继续保留。本版只修复已确认的核心逻辑，不新增权重、悬赏或甘特图。

## 修改

1. 取消的复习轮次从三个栏目（含必做）和逾期自动处理排除，不再因为残留可见任务而产生扣分；原事件、轮次历史和其他系列不变。暂停必做系列仍显示既有义务，但暂停期间不参与自动顺延；停止系列记录可选 `stoppedAt`，取消所有后续未完成轮次，阻止重新排期。
2. 必做复习自动顺延时，把同一轮次的有效 `due`、目标日期、关联时间点和轮次 `taskRef` 一起更新；保留最初 `originalDue` 与独立调整历史，不创建第二个复习轮次，也不重复扣分。长期拓展的历史自动顺延仍沿用原有不变更到期刻度的约定。
3. 手动“结束计时”需要确认。取消无改动；确认后只结束当前计时会话，保留实际时间片段，不完成任务、不结算积分。保存失败保留可重试操作。完成任务时原有自动结束逻辑不额外弹确认。
4. 计时确认弹窗在“开始/继续”成功且本次没有未保存编辑时关闭；如果修改过备注、计划估时或分类则保留弹窗，避免丢失未保存内容。
5. 完成事件在提交时从当前任务重新读取最终已保存的任务名称，记录快照并用于自动生成文本。用户手工改写的文本保留，历史事件名称不会随任务未来改名漂移。
6. 浮动计时条若有明确 `span` 起止时间，改为按墙钟时间推进，右端对应计划截止时刻，另列有效学习时长；暂停仍经过计划时间，截止后显示超过截止时间。无明确起止时继续用既有“预计分钟／累计时长”规则。

## 兼容性和回退

- 主数据继续为 `focusPlanData.v1`；所有新属性均为可选，既有计时段、积分流水、备份和笔记原样保留。
- 174.1.0 对应源码、gh-pages 预先留存可回退提交。代码回退不自动修改用户本地保存的数据。
- 发布前须通过 Node 存储回归、全部浏览器交互矩阵（含 174.2 新增测试）、构建/typecheck、离线恢复。安卓 Edge 真机触摸、输入法、锁屏恢复仍需真实设备验收。
