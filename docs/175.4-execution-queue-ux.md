# 175.4.0 · 执行队列移动端交互

- 三栏任务不再常驻显示“＋入队”；进入现有任务完成／习惯打卡弹窗后按需入队，保留未提交的备注。
- 队列添加弹窗使用微型三栏批量选择；360px 及以上并列三栏，更窄屏幕使用栏目切换。支持当天三栏内已安排的习惯。
- 习惯入队记录当天次数快照，真正打卡次数增加后移出本次执行；可继续打卡的达标习惯允许重新入队。入队、跳过和清理不操作积分或打卡。
- 习惯引用必须属于当前用户日且仍在三栏安排里，跨日及撤销后的旧队列引用不会被自动复活。习惯与任务都按规范化引用去重。
- 队列省略号改为屏幕内弹窗，避免窄屏、换行和滚动裁切。习惯仅支持调整原习惯安排，不借用任务删除操作。
- 保留原始任务／习惯身份、栏目、完成历史、计时片段及积分账本；数据版本仍为 1。
- 发布流程：推送 main 后，CI 构建并运行存储与浏览器检查；成功后仅创建构建候选分支，不等于 gh-pages 部署。
