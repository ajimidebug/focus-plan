# 173.7.0 间隔复习集成与回退审计

基线：173.6.0，`9d009c6ecf6171a22368d6b497d46caf6e0da90d`。回退分支：`release-173.6.0-rollback-20261029`。上游参考提交：`3e8d7c5`、`d857824`；选择性移植排期管理与历史展示，不合入“移动即完成”、按文字日期去重、旧直接发分及清空历史行为。

## 最终行为

- 长期拓展完成方式增加间隔复习，进入独立的小表单。系列管理放在长期拓展下方折叠区，不纳入当天完成率；每轮是一个有稳定ID的普通单次任务，默认理想栏目、1分，可设0分或其他栏目。
- 支持指定北京时间及30分钟、2小时、4小时、1天、3天快捷安排；完成确认还支持自定义分钟。默认不安排后续，确认时可从实际完成时刻计算下一轮；多次手动添加允许同日独立轮次，不按名称或日期合并。
- `memoReview`可选模块保存系列、轮次、修改历史和执行任务引用。完成事件保存当时标题、原定时间、实际时刻、结果和下轮关联；计划时间点进入现有预计轨，执行和完成复用现有计时、笔记、积分事件及撤销。
- 结果默认未记录。掌握程度不改变奖励；不叠加上游复习分和全轮奖金。新增同日任务后整组奖励按保存后的资格判断。
- 改期通过同一个核心同步预计时间点和任务安排，保留原定时间和调整历史；自动顺延保留原始到期时刻，不增加轮次或重复扣分。过期轮次可从到期摘要打开，跨日接续先保存安排，之后再计时。
- 撤销本轮完成时，未编辑且未开始的关联下轮取消；已改期、开始或完成的下轮保留，并标注前置完成已撤销。既有计时不会被删除。
- 暂停结束活动计时并隐藏选做待执行轮次及其预计点；恢复保持原定时刻。已安排必做的未完成义务仍保留，暂停或取消不帮助取得整组奖励。停止后续只取消未完成轮次。
- 删除及恢复复用现有事务差异恢复机制，新增复习状态也纳入差异；仅恢复任务时不恢复积分。取消安排与删除任务分开。
- 原任务详情可建立复习；旧sp记录按用户选择接入，保留原记录及移动记作完成的来源标记，不补发积分；未完成轮次的need/hits转换为剩余独立执行次数，保留原数据附录。来源ID相同的重复接入阻止。
- 不接入旧知识卡批量完成、按日去重和补分路径。本版可按任务备注或现有外部材料复习，尚无复习窗口内卡片交互，也不自动推断掌握结果或使用FSRS。

## 保存与验证

所有写入使用现有保存事务：校验异常回滚，持久化失败保留同一次操作，重试只保存、不重复执行。新增模块及关联结构校验；未知模块版本或损坏记录拒绝导入，旧v1无复习字段照常使用。完整备份和升级前快照沿用现有机制。

Node新增覆盖同日及同名独立轮次、实际完成时间排期、普通积分单次发放、撤销下轮依赖、计时保护、改期和时间轴同步、暂停与必做义务、删除恢复、保存失败重试、旧计划接入、04:00、备份重载、坏结构拒绝，以及实际173.6存储代码的往返保存。另加入320、390、1280宽度的浏览器回归，并继续运行既有功能回归。

测试使用隔离合成数据，未读取用户手机实际数据。应用打开／恢复前台时提供到期摘要；不承诺锁屏后台定时通知。真实Android Edge输入法、锁屏和离线更新仍需真机验证。

## 代码回退和个人数据恢复

1. 回退分支固定升级前代码。需要代码回退时，从该提交重新构建发布，不能删除用户存储。
2. 存储测试证明173.6的存储层能读取并保留新可选字段；这只证明数据往返，不证明173.6业务界面理解复习关系。旧界面不能维护新的轮次状态，不应继续操作复习任务。
3. 若需要回到升级前完整使用状态，先下载当前含新增记录的完整备份，再由用户本人明确确认恢复升级前快照／完整备份；新版期间记录保存在另存文件中，不能声称自动无损合并。
4. 本次发布不自动恢复、清除或替换个人数据。自动快照仍在原浏览器中，独立下载的完整备份是额外恢复路径。
