# 175.6.0 · 甘特图概览 / 详细双模式与日期轴

## 交互规则

- 甘特图顶部提供「概览 / 详细」模式切换，和「月 / 半年 / 两年 / 全部 / 自定义日期」范围选择相互独立，使用原有 `gantt-175:` localStorage 偏好记忆；旧用户默认详细模式。
- 概览将完整的已选时间范围适配当前甘特图容器宽度，无横向滚动；纵向任务仍可滚动，分组与已完成折叠逻辑保持。
- 详细模式沿用原有独立可横向滚动的宽时间轴；鼠标/触笔拖动修改起止日期时保留二次确认。概览禁用拖动改期，点击任务名或任务条进入原有编辑。
- 星期和日期标签依据时间跨度与容器宽度自动稀疏化。短范围显示日期与星期，中范围优先显示星期一，长范围按月份/年份；标签分上下两级，避免互相覆盖。
- 日期背景自适应按日、周、月、年为单位交替淡色；今天红线、已过去范围、共享截止日虚线、任务条都以相同的 UTC 自然日索引投影到共享日期轴，跨月跨年不偏移。用户日 04:00 归属规则未更改。
- 宽度极短的任务在概览中显示小圆点，标题、原始计划日期及打开编辑入口保留，不将可见标记的长度作为实际工期。
- 浏览器旋转/缩放时刷新标记密度；任务条和日期背景使用百分比位置，随容器宽度变化而对齐。

## 数据和非目标

仅修改甘特图界面、视图偏好与相关测试；不修改 `dataVersion`、任务安排日、截止日期、依赖、完成记录、积分、计时、复习期次、复习顺延、导入导出格式及历史数据。持续周期复习的跨日顺延本次暂不修改。

## 验收与风险

1. 320、360、390、430px 以及桌面宽度下，概览没有甘特图横向滚动或整页横向溢出，完整日期范围均能看到。
2. 月 / 半年 / 两年 / 全部 / 自定义范围切换、页面重绘后选择保持；详细模式仍有独立水平滚动。
3. 任务条、日期背景、今天红线、DDL 虚线共享日期基准；长任务、里程碑、仅截止日、已达成与无排期正常展示。
4. 概览点击可编辑，但不能误触拖动改期；详细模式拖动依旧弹确认。
5. 分组、折叠、依赖线、移动端点击区域、主题切换及旧数据导入导出回归；修改显示不写入业务账本。
6. 长跨度按较大时间分组，日期背景 DOM 数量封顶，避免多年跨度逐日渲染。
