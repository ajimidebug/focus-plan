# 173.5.0 延期记录、计时进度与默认积分审计

基线：173.4.1，`beadc3ffa3c22ee089fccc53cbedba2791aed8fa`。代码回退分支：`release-173.4.1-rollback-20261029`。

## 延期与完成口径

- 跨日期延期保留原日期的只读记录，显示“未完成 · 已延期至日期”，目标日期继续执行同一任务。新延期使用深拷贝保存标题、备注、子项和分组，后续编辑不串改原日期内容。队列任务跨日期重新安排也保留当时快照。
- 只保留一个可执行任务及原有规范身份；原日期不出现第二套计时、勾选、编辑或奖励操作，可查看当前任务或在详细列表补记完成。重复延期到相同目标不产生重复副本；连续延期保留各日期记录。
- 原日期未完成的延期项保留在完成率分母，目标日期完成不会把原日期改成完成。必做整组与全部完成奖励也检查原日期未完成的延期项，避免通过移走任务取得奖励。待做数量仅数本页可执行项。
- 补记沿用实际完成日、逾期原额纠正和不追补历史整组奖励的既有规则；回到此前日期时清理该日同身份的失效占位，避免引用循环和重复活动任务。
- 旧延期缺少快照时标注“旧延期记录，内容按现存记录展示”，不推测无法还原的历史文字。任务退回待安排队列属于原有取消安排操作，不新增日期延期快照承诺。
- 自动顺延沿用原罚分与去重规则，不因新增历史显示再次结算。实际时间继续按北京时间04:00切分，原会话与片段保持同一份，不按延期副本累加。

## 计时状态与显示

悬浮窗和任务详情共用同一刻度计算。有效预计时长内显示预计进度；恰好达到预计时长保持100%，严格超过时自动切换为超时刻度，无需暂停、重开或刷新。同一会话ID、真实片段和草稿继续保留。暂停冻结进度，继续后只增加实际执行时间。

超时刻度每15分钟一格、每小时一段，完整小时数另列；整小时边界保持满段，到下一秒进入新段。无预计时长显示本次用时刻度，不标为完成百分比。一次性任务比较累计用时，重复任务沿用所选用户日／浮窗今日口径。

进度采用青绿至蓝色渐变，超时切换琥珀至珊瑚色，轨道与左端3px状态标记同步改变。详情与展开条高8px，收起条高6px；刚超时一秒时即使实际填充很短，状态仍可辨认。暂停保留可读亮度，减少动态偏好下关闭宽度动画。详情填充补齐`display:block`与高度，修复原先内联元素实际宽度为0的问题。

## 默认积分与数据兼容

- 新理想任务默认1分，表单、奖励兜底、旧任务模块与积分规则展示一致。
- 首次载入旧数据时，先把既有理想任务缺失的积分固定为旧默认值，再将旧默认10改成1。已有明确积分（含0）和其他自定义默认值保留，账本不重写。
- `memoIdealDefaultVersion:1`使迁移只执行一次；升级后用户主动把默认值设回10，刷新仍保留10。导入没有该标记的旧备份也执行同样迁移，未知标记拒绝导入。
- 数据总版本仍为v1，新增延期元数据经过校验。沿用完整备份、更新前快照及保存失败保护；代码回退不等于个人数据回退，不清除存储。
