# 175.1.0 · 统一甘特图与任务分组

## 核心产品规则

- 任务首页保留三栏，长期任务甘特图位于其下，待安排任务放在甘特图下方；待安排与更多页使用同一队列和历史逻辑。
- 全部独立一次性任务（包含当前三栏、队列及保留的完成记录）默认显示在甘特图中，不创建甘特专用任务副本。复习轮次和重复周期生成的实例仍由原模块管理，避免大量重复。
- 一次性任务使用现有一次性完成状态，长期每日推进项目使用既有独立达成标记。甘特日期仅表示计划区间或截止点，不代表实际完成率。
- 默认折叠“未分组”。甘特外层、各分组、显示数量及筛选/范围等视图偏好保留本地记忆。
- 所有甘特任务共享 memoTaskGroups；分组管理支持创建、重命名、排序、删除与迁移。删除分组应保留任务、积分、计时、依赖及完成历史。
- 前置依赖默认显示同组任务，允许显式启用跨组选择。一次性任务与长期项目可互为前置。依赖仅警告，不自动改期、禁止打卡或自动结算。
- 原有长期项目依赖字符串（项目 ID）继续有效；新的一次性引用使用 once:<id>，使一次性任务从三栏转移到队列时仍可解析。新增字段均为原记录的可选属性，保留顶层 dataVersion 1。
- 修改计划起止日期不会自动改变三栏安排日期；日期范围可以双击同一天形成单日计划，也可以显式改为仅截止日的时间节点。保存前都需确认。
- 日期范围编辑使用现有 Quasar QDate，范围选择以及清空/单日/仅截止日等快捷操作。显示自然日今天红线、过去日期背景和共享 milestones 截止日虚线。
- 甘特图参考线遵循北京时间自然日，任务完成及统计仍遵循原有北京时间 04:00 用户日规则。
- 全局截止日仅从 milestones 读取，过滤当前可见时间范围，同日多个节点合并。其显示不自动创建任务或依赖。

## 数据引用与兼容

- 甘特图混合依赖写在原任务 memoGanttDependencies 中，项目间原有依赖 ID 不改变，一次性任务为 once:<原任务ID>。
- 跨日任务改期采用原有源/目标引用，甘特图跳过历史改期副本；队列与日期任务沿用原 ID。遇到缺失前置时应提示缺失，不能静默映射到同名任务。
- 模块导入导出增加一次性任务的甘特元数据及分组名称；混合依赖需按新生成任务 ID 重映射，并拒绝缺少前置任务的输入。
- 当前完整数据备份仍是权威恢复手段；模块导出用于新建计划，不可恢复历史积分与计时。
- 不更改历史账本、完成事件、计时片段及已归属用户日。

## 验收重点

1. 一次性任务在必做/理想/拓展/队列只产生一个甘特节点；已完成任务不被误作每日推进。
2. 默认未分组折叠、整体展开记忆、页面切换及重绘稳定。
3. 同组候选默认、跨组选择、一次性↔长期依赖、缺失前置及循环依赖拒绝。
4. 任务改期、队列流转、完成/撤销后，甘特引用始终有效。
5. 两次选取范围、第三次重选、单日/仅截止日/清空、取消不写入。
6. 自然日今天、过去区域、多个截止日、跨月跨年、分组筛选与缩放位置准确。
7. 分组删除迁移、旧备份恢复、混合依赖模块导入导出、保存失败重试。
8. 移动端 390px 与极端长名称、跨组连线、页面横向滚动、表单弹窗遮挡。

## 非目标

不恢复原作者旧队列的自动副本与自动下一条结算，也不改变时间轴的计划/执行/完成三轨结构。不自动规划依赖工期或跨组同步时间。
