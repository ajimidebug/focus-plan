# 175.14.0

轮次计划保存独立起止日期，使用甘特图的双击范围日历。轮次按用户日排序且不得重叠，可预排任意数量的轮次、调整开放轮次日期和提前结束正在进行的轮次。提前结束当日仍归本轮，下一轮最早次用户日开始。确认时暂停本轮仍运行的计时，保留实际片段。未完成任务沿原身份进入下一轮，没有下一轮时进入待安排。创建新轮可接入待安排任务。关闭结果使用独立快照，备注与原计划结束日期保留。

甘特一次性任务与长期项目按明确截止日期关联开放轮次。手动安排优先，可恢复按截止日自动安排。修改截止日或轮次日期后自动归属重新计算，手动选择保留并显示日期冲突。两处共用原任务引用、计时和完成事件，单次积分依照原业务处理。项目每日推进与整体达成保持现有独立语义。

随手记进入页面后同步定位编辑框与页面，等待布局稳定并响应进入期间的字体、视口及内容变化。用户开始滚动或点击后停止自动定位，键盘继续由主动编辑触发。

三天模块从 version 1 迁移为 version 2，保留任务 ID、计时引用、未来安排和已关闭结果。旧数据首次迁移保留当前及后续两轮，之后由用户新建轮次。轮次日期、关联字段、历史及未知版本经过备份校验。175.13 及更早版本不理解新模块，回退前应使用对应旧备份，不能让旧程序写入新版轮次数据。

验证覆盖迁移、非三天范围、重叠、提前结束、空档、自动与手动关联、源任务完成与撤销、历史快照、存储失败重试及手机末尾定位。发布继续使用准确源提交的已验证候选，并进行线上资源与启动校验和归档。
