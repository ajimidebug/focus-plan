# 173.4.0 实施与发布审计

范围：实际执行片段完整复制、任务弹窗底部计时主操作、手机三栏同屏。原始任务、账本、利率、奖励与长期任务结构保留；不增加撤销计时。

## 执行片段与复制

- 完整复制直接投影 `memoSchedule.sessions[].chunks`，包含未完成、暂停、结束和运行中的实际片段，不依赖完成事件。投影只读，不自动停止会话、不回写原始时间、不推测缺失区间。
- 全部任务类型按实际发生的北京时间04:00用户日切分。跨午夜但未过04:00保持同一用户日；原片段编号跨日保持，截取范围与原始起止另列。每日推进／习惯的完成状态按执行日读取。
- 每段包含秒级日期时间、时长和稳定编号。进行中段截至一次复制快照的统一时间；后续同编号更新替换旧快照。任务内及当日跨任务合计按区间并集计算，重合原始片段仍可查。
- 同标题任务按逻辑引用区分，无法解析的关联保留会话标题与历史状态。旧完成快照作为历史引用保留，明确与执行明细同编号或重合区间不重复累计；不删除用户手写文段。
- 结构化复制基线可选增加 `execution`，与任务事实及流水分开比较。只增加往日计时会补该日执行明细，不带出所有任务／财务日报。首轮升级为未知的往日复制状态建立基线，不倾倒全历史。
- 预览不推进基线；复制成功或手动确认后沿用原事务保存。相同用户日的重复复制保留待补记范围；切回往日不丢未来已知基线。重复制仍重放确切原文；选区复制不改。
- 存储保持数据v1，新增基线严格校验。旧版忽略新增可选字段；旧备份仍可读取。

## 弹窗与窄屏

- 使用现有弹窗底部操作区，正文独立滚动。计时按钮通栏48px，开始／继续／暂停共用原操作；完成按钮独立，保存／编辑／取消为辅助操作。
- 原有日期限制、输入草稿、积分及完成事务保留。每秒仅更新计时文字、刻度和明细预览，不重建输入框。暂停冻结；无预计及超时使用时间刻度，不声称完成百分比。
- 保存失败保留底部重试与错误，重试只保存待提交事务，不重复创建片段；成功后清除旧错误。关闭弹窗后不保留独立计时轮询器。
- 三栏取消510／540px最小宽度，保持三等分、4—6px间隔；没有内层横向轮播。完整任务名与习惯名换行，积分及状态另行，保留原完成折叠与进度口径。
- 按钮布局只作用于任务完成弹窗；未改其他弹窗。沿用原可视窗口键盘适配，极低高度允许原弹窗整体滚动。
